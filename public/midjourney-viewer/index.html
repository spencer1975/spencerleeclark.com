Midjourney Viewer is an Obsidian plugin that organises your downloaded Midjourney images entirely offline: a searchable gallery with the full prompt for every image, and beautiful galleries you can drop straight into your notes. Your images never leave your machine.

What it does

Your library, with its memory intact

Midjourney caps filenames at about 100 characters. Long prompts get cut off, parameters vanish, and a folder of downloads becomes a folder of mysteries. The plugin reads what the image itself remembers.

PNG
Full prompts from PNG metadataThe complete prompt, parameters, job ID and author are read from the metadata embedded in each PNG. Long prompts survive, exactly as you wrote them.
/
Search that speaks MidjourneyPhrases, exclusions and parameter queries: "--ar 16:9" city -neon. Terms match across prompt, parameters, filename, job ID and username.
⤢
A proper lightboxArrow-key navigation, clickable parameter chips, copy prompt / full command / path, insert into the open note, open externally.
```
Galleries inside your notesEmbed grid, masonry, strip, slideshow or random galleries with a code block, built through a dialog with live preview and edited later with one click. No syntax to memorise.
ab
Filename parsing as fallbackFor non-PNG files the parser recovers the prompt, normalises parameters and extracts the job UUID and variant from the filename.
⚡
Fast on big librariesThumbnails render lazily and cache to disk; metadata is read once per file; full-size images stream one at a time, so memory stays flat.
🔒
Offline and privateEverything happens on your machine. No accounts, no uploads, no network requests. Your library stays yours.

Install

Three steps to your gallery

01
Install the pluginClick Install in Obsidian, or go to Settings → Community plugins → Browse and search “Midjourney Viewer”. Manual install: files on the latest release.
02
Point it at your downloadsIn the plugin's settings, set the library folder. A Browse… button is provided. Thumbnails and prompts are indexed once and cached.
03
Open the viewerClick the ribbon icon or run Open Midjourney viewer. Press / to search. Right-click the ribbon icon to insert a gallery embed.
# embed a gallery in any note (the dialog writes this for you)
```midjourney
folder: portraits
style: masonry
match: --niji
```
